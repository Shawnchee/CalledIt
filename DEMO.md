# CalledIt — Demo Video Shot List (≤5 min)

The replay match runs ~3 min on a real-time clock once you hit **Kick off**. Below is exactly what to
tap and say. Calling the **5 starred** props correctly = **1,843 pts → you finish #1 🏆** (the sharp
bot "Maxi" finishes on 1,793 — he calls the finale wrong). You don't have to be fast: each window is
12–14s and tapping is instant (the on-chain receipt confirms in the background).

## Before you hit record
- [ ] **Phantom set to Devnet** (Settings → Developer → Testnet/Devnet), and the wallet **funded** —
      run `solana airdrop 2 <your-phantom-address> --url devnet` (each call costs ~0.0015 SOL rent + fee).
- [ ] Open the **deployed URL** (or `npm run dev`). Screen + mic recording on, 1280×800+.
- [ ] Have a Solana Explorer tab ready (devnet) for the receipt reveal.

## If a call window closes before you tap
No problem — skip it; the match keeps going. You only need the 5 starred calls to finish #1. The two
**hero on-chain moments** are the **27% goal** and the **12% red card** — make sure those two land on camera.

## Backup line if devnet is slow
If a receipt toast is still "writing…" when you move on, say: "the receipt settles on devnet in the
background — here's one that already landed" and open `Your receipts` / Explorer. (`record_call`,
`settle_call`, `initialize_config` are all already verified on devnet — see `SUBMISSION.md`.)
